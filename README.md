Vice Booth is an offline web app that turns any photo into GTA-style photo-booth strip cover art: one photo fills four snapshot frames with a different crop per frame (or four different photos, one per frame), each frame drag-to-pan and scroll-to-zoom, over a procedural Vice City sunset backdrop with a skyline and palm silhouettes, bold outlined title lettering, four colour grades (Sunset, Neon Night, Pastel Vice, Noir), film grain and vignette, and one-click PNG export at 1080 x 1350, 1080 x 1080 and 1920 x 1080. Everything runs in the browser from static files — no uploads, no network requests, no fetched fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
